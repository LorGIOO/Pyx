# Pyx template

The starting point for a new piece of work: the same structure as the other examples, empty.

- **Open** `1. Main/_Preamble.pltx` in Pyx and press **Compile & view** (Ctrl+Shift+B).
- `1. Main/pyxstyle.sty` — the document's look (margins, colours, cover, `\pass`…).
- `2. Chapters/` — one file per chapter, included with `\input{…}` from the main one.
- `999. Resources/` — images, data and calculations.

Copy the whole folder, rename it and start writing.
