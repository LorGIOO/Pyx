Pyx example projects (fictitious data).

Unzip one wherever you like, open in Pyx the main file its README.md names
and press «Compile & view» (Ctrl+Shift+B).

  00-template                          empty template with a .sty and chapters
  01-calculation-report                complete report: CSV, Excel, handcalcs, pint, Jupyter
  02-handcalcs-and-units               handcalcs and units with pint
  03-jupyter-notebook                  a report that only calls a notebook
  04-tables-plots-and-conditionals     pandas tables, plots and \pyif
  05-excel-data                        Excel and CSV data with \hoja and \celda, no Python

Also at https://lorgioo.github.io/Pyx-web/en/examples/
